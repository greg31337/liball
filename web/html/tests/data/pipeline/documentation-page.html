Configure the widget client

The client reads an endpoint, a retry policy, and a bounded timeout. Configure these values once during application startup so every request uses the same reviewed behavior.

Basic configuration

WidgetClient client = WidgetClient.Create("https://api.example.test");
client.SetTimeout(30);

Keep credentials outside source control. Rotate them through the deployment environment, verify failures explicitly, and record enough context to diagnose a rejected request without logging secrets.

Retry behavior

  1. Retry temporary failures.
  2. Apply a strict attempt limit.
  3. Stop when cancellation is requested.
