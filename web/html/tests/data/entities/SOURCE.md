`named-character-references.tsv` is a normalized snapshot of every property in
the upstream JSON object, sorted by reference name using ordinal comparison.
Each row contains the name, the first Unicode scalar value, and the second
scalar value or `-1` when there is only one. The two leading comment lines are
repository metadata and are not upstream data.
