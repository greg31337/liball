# Color font test assets

These files come from the Google Fonts `color-fonts` repository at commit
`0046ea4c3b69e9fbbe464c2594816894e3aa5e4b`:

- `fonts/test_glyphs-glyf_colr_1_variable.ttf`
- `fonts/samples-untouchedsvg.ttf`
- `fonts/samples-sbix.ttf`

The upstream repository describes these as generated fonts for color-font
implementation testing. The copied `LICENSE.txt` is its Apache License 2.0.
The fixtures are stored locally so normal test execution never requires a
network connection.
