# Specification Sources

Retrieved on 2026-08-24.

- `gif87a.txt` — CompuServe, *Graphics Interchange Format*, version 87a (15 June 1987). Source: https://www.w3.org/Graphics/GIF/spec-gif87.txt
- `gif89a.txt` — CompuServe, *Graphics Interchange Format*, version 89a (31 July 1990), including the deferred-clear-code clarification. Source: https://www.w3.org/Graphics/GIF/spec-gif89a.txt
- `netscape2.0-loop-extension.html` — archived programming description of the de-facto `NETSCAPE2.0` looping application extension. Source: https://web.archive.org/web/20140830100320id_/http://odur.let.rug.nl/~kleiweg/gif/netscape.html
- `rfc2045.txt` — RFC 2045, *Multipurpose Internet Mail Extensions (MIME) Part One: Format of Internet Message Bodies*, one of the references registered by IANA for `image/gif`. Source: https://www.rfc-editor.org/rfc/rfc2045.txt
- `rfc2046.txt` — RFC 2046, *Multipurpose Internet Mail Extensions (MIME) Part Two: Media Types*, including the `image` top-level media type and GIF registration context. Source: https://www.rfc-editor.org/rfc/rfc2046.txt
- `iana-image-media-types.csv` — current IANA image media-type registry, including `image/gif`. Source: https://www.iana.org/assignments/media-types/image.csv

The GIF87a and GIF89a documents are the format implementation references. The Netscape document covers loop-count bytes not standardized by GIF89a. RFC 2045, RFC 2046, and the IANA registry are identification and interchange references; they do not alter GIF binary parsing.
