# WebP Reference Sources

Downloaded on 2026-08-25. The three format documents are sufficient for the
normative RIFF container, lossy VP8, lossless VP8L, alpha, metadata-chunk, and
animation rules implemented by this library. The two libwebp documents are
non-normative reference descriptions used to check the breadth of public
decode, encode, mux, demux, animation, and command-line option workflows.
