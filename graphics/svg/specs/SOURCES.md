## Scope notes

- SVG 2 is the primary semantic target; SVG 1.1 is retained as a compatibility
  baseline because real-world authoring tools and the mature test suites still
  rely on it.
- The CSS set is deliberately limited to modules that directly define SVG
  parsing, styling, layout, paint, compositing, or animation behavior.
- The OpenType landing page and locally downloaded table pages cover the SFNT,
  outline, layout, variation, web-font, and color-font formats represented by the
  current public font layer.
- External library pages are evidence for feature discovery and architecture only;
  their source code is not a dependency and must not be copied into `src/`.
