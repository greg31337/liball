# DOCX Specification Sources

Large reference files are available through [Reference downloads](../REFERENCE-DOWNLOADS.md). The source inventory below also records historical acquisitions.

Retrieved 2026-08-24 from the publishers' canonical locations.

- ECMA-376 Part 1, Fundamentals and Markup Language Reference, fifth edition (2016), including the Strict XML schemas: https://dev.ecma-international.org/wp-content/uploads/ECMA-376-1_5th_edition_december_2016.zip
- ECMA-376 Part 2, Open Packaging Conventions, fifth edition (2021), including the OPC XML schemas: https://dev.ecma-international.org/wp-content/uploads/ECMA-376-2_5th_edition_december_2021.zip
- ECMA-376 Part 3, Markup Compatibility and Extensibility, fifth edition (2015): https://dev.ecma-international.org/wp-content/uploads/ECMA-376-3_5th_edition_december_2015.zip
- ECMA-376 Part 4, Transitional Migration Features, fifth edition (2016), including the Transitional XML schemas: https://dev.ecma-international.org/wp-content/uploads/ECMA-376-4_5th_edition_december_2016.zip
- ECMA Office Open XML overview: https://dev.ecma-international.org/wp-content/uploads/OpenXML-White-Paper.pdf
- Microsoft Word Extensions to the Office Open XML File Format, MS-DOCX: https://officeprotocoldocs-f5hpbjgea6b8gneq.b02.azurefd.net/files/MS-DOCX/%5bMS-DOCX%5d.pdf
- Microsoft Office Implementation Information for ISO/IEC 29500, MS-OI29500: https://officeprotocoldocs-f5hpbjgea6b8gneq.b02.azurefd.net/files/MS-OI29500/%5bMS-OI29500%5d.pdf
- Microsoft Office Drawing Extensions to Office Open XML, MS-ODRAWXML: https://officeprotocoldocs-f5hpbjgea6b8gneq.b02.azurefd.net/files/MS-ODRAWXML/%5bMS-ODRAWXML%5d.pdf
- Microsoft Office Shared Extensibility in Office Open XML, MS-OEXTXML: https://officeprotocoldocs-f5hpbjgea6b8gneq.b02.azurefd.net/files/MS-OEXTXML/%5bMS-OEXTXML%5d.pdf
- Microsoft Office Macro-Enabled File Format version 2, MS-OFFMACRO2: https://officeprotocoldocs-f5hpbjgea6b8gneq.b02.azurefd.net/files/MS-OFFMACRO2/%5bMS-OFFMACRO2%5d.pdf
- RFC 3986, URI Generic Syntax: https://www.rfc-editor.org/rfc/rfc3986.txt
- RFC 4648, Base-N Encodings: https://www.rfc-editor.org/rfc/rfc4648.txt

The ECMA archives were unpacked so the normative PDFs and applicable XSD files can be used directly. SpreadsheetML and PresentationML schemas remain because WordprocessingML packages can contain embedded objects and DrawingML relationships that refer to those vocabularies.
