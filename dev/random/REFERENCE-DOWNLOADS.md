# Reference downloads

The references in the first table are linked instead of redistributed because their publication notices or publisher terms restrict reproduction. Large downloads are listed separately below. Download them for local reference under the publisher's terms; a free download does not grant permission to republish it.

Paths are relative to this project. The top-level `.gitignore` excludes these local copies. Some links open a publisher page where the edition must be selected or access terms accepted.

| Local reference path | Short description | Download or publisher page |

Devroye explicitly permits copying in the [preface to the web edition](https://luc.devroye.org/rnbookindex.html). This book is linked here to keep the repository small.
