# Local standards and research corpus

Large reference files are available through [Reference downloads](../REFERENCE-DOWNLOADS.md). The source inventory below also records historical acquisitions.

Retrieved on 2026-08-27. Dated W3C Recommendation URLs are used where available so the normative text does not drift. Retained test-suite ZIP files are upstream snapshots; the XSLT 3.0 suite is download-only. Suite READMEs remain available for quick inspection.
