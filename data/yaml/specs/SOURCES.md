# Specification Sources

Retrieved on 2026-08-25 from authoritative publishers.

- `yaml-1.2.2.html`: published YAML 1.2.2 specification, https://yaml.org/spec/1.2.2/
- `yaml-1.2.2.md`: YAML 1.2.2 specification source, https://raw.githubusercontent.com/yaml/yaml-spec/main/spec/1.2.2/spec.md
- `yaml-1.2.2-changes.html`: YAML 1.2.2 change summary, https://yaml.org/spec/1.2.2/ext/changes/
- `yaml-1.1.pdf`: YAML 1.1 specification used for compatibility behavior, https://yaml.org/spec/1.1/current.pdf
- `yaml-1.1-types.pdf`: YAML 1.1 language-independent type index, https://yaml.org/type/index.pdf
- `yaml-1.1-type-*.pdf`: definitions for the map, ordered-map, pairs, set, sequence, binary, Boolean, float, integer, merge, null, string, and timestamp tags, downloaded from `https://yaml.org/type/<type>.pdf`
- `rfc8259-json.txt`: JSON data interchange format used by the JSON schema and JSON-compatible conversions, https://www.rfc-editor.org/rfc/rfc8259.txt
- `rfc3339-timestamps.txt`: Internet timestamp profile relevant to timestamp conversion, https://www.rfc-editor.org/rfc/rfc3339.txt
- `rfc4648-base64.txt`: Base64 definition relevant to the YAML binary tag, https://www.rfc-editor.org/rfc/rfc4648.txt
- `yaml-test-suite-data-2022-01-17.tar.gz`: upstream conformance data release already pinned by the test project, https://github.com/yaml/yaml-test-suite/archive/refs/tags/data-2022-01-17.tar.gz
- `yaml-test-suite-readme.md` and `yaml-test-suite-license.txt`: upstream suite format and license, https://github.com/yaml/yaml-test-suite

YAML 1.2.2 has no PDF at the otherwise conventional `spec.pdf` URL, so both its published HTML and authoritative Markdown source are retained.

The following non-normative references are retained for the feature comparison requested by the project prompt:

- `comparison-yaml-javascript.html`: layered lexer, parser, composer, document, schema, and stringify API, https://eemeli.org/yaml/
- `comparison-pyyaml-readme.md`: PyYAML project capabilities and API overview, https://github.com/yaml/pyyaml
- `comparison-ruamel-yaml-roundtrip.html`: round-trip editing and comment-preservation behavior, https://yaml.dev/doc/ruamel.yaml/detail/
- `comparison-js-yaml-readme.md`: schema, loading, and dumping behavior, https://github.com/nodeca/js-yaml
- `comparison-go-yaml-v3-node.go`: Go YAML v3 node model and public fields, https://github.com/go-yaml/yaml/blob/v3/yaml.go
- `comparison-yamldotnet-serializer.md` and `comparison-yamldotnet-deserializer.md`: object conversion behavior, https://github.com/aaubry/YamlDotNet/wiki
- `comparison-yaml-library-development.html`: YAML library implementation guidance, https://www.yaml.info/libraries/dev.html
- `yaml-test-matrix.html`: comparative YAML Test Suite results, https://matrix.yaml.info/
