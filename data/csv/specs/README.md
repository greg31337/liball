# CSV Reference Material

Downloaded on 2026-08-24 for offline design and conformance work.

- `rfc4180.txt` — RFC 4180, the common CSV format and `text/csv` media type: https://www.rfc-editor.org/rfc/rfc4180.txt
- `rfc7111.txt` — RFC 7111, URI fragment identifiers for `text/csv`: https://www.rfc-editor.org/rfc/rfc7111.txt
- `draft-shafranovich-rfc4180-bis-07.txt` — expired, non-normative proposal updating RFC 4180; retained for its survey of current CSV practice: https://www.ietf.org/archive/id/draft-shafranovich-rfc4180-bis-07.txt
- `iana-text-csv.txt` — current IANA `text/csv` registration: https://www.iana.org/assignments/media-types/text/csv
- `w3c-tabular-data-model.html` — W3C CSVW model, best-practice CSV, and parsing guidance: https://www.w3.org/TR/tabular-data-model/
- `w3c-tabular-metadata.html` — W3C CSVW dialect, schema, datatype, null, and validation metadata: https://www.w3.org/TR/tabular-metadata/
- `owasp-csv-injection.html` — OWASP CSV/formula-injection threat and mitigation guidance: https://owasp.org/www-community/attacks/CSV_Injection
- `python-csv.html` — Python standard-library dialect, reader/writer, and sniffer behavior: https://docs.python.org/3/library/csv.html
- `duckdb-csv-auto-detection.html` — DuckDB dialect, header, and type auto-detection behavior: https://duckdb.org/docs/current/data/csv/auto_detection.html
- `csvhelper-overview.html` — CsvHelper feature and configuration overview: https://joshclose.github.io/CsvHelper/
