dictType Metadata

dictType tags may be used by a profile builder to identify the usage conditions for which a profile is intended.

Since tags based on the tag type of this proposal are not intended for use in the computational operation of a CMM, they can be used in any profile version, including ICC v2, v4 and iccMAX profiles. They provide a structure for use in consistently and openly encoding profile description and usage details in a profile. This will enable improved manual and/or automated profile search and selection, so that a selected profile corresponds to the current color management use case.

Full details of dictType tags can be found in the Dictionary Type and Metadata TAG Definition specification amendment.
