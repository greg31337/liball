# Specification Sources

Some local reference files have been replaced by links. See [Reference downloads](../REFERENCE-DOWNLOADS.md) for the current download-only files and their original paths. The inventory below also records historical acquisitions.

Retrieved 2026-08-24. These local copies cover the public interoperability and chemistry rules planned for this library.

| Local file | Source | Relevance |
| --- | --- | --- |
| `opensmiles-1.0.pdf` | [OpenSMILES specification](http://opensmiles.org/opensmiles.pdf) | Open grammar and semantics for SMILES parsing and writing. |
| `daylight-theory-manual-4.9.pdf` | [Daylight Theory Manual](https://daylight.com/dayhtml/doc/theory/index.pdf) | Original-language descriptions of SMILES, SMARTS, canonicalization, fingerprints, and similarity. |
| `ctfile-formats.pdf` | [CTfile Formats](https://www.wincept.eu/toxlab/pdf/ctfile.pdf) | Originating MDL/Accelrys format description for MOL V2000, MOL V3000, and SD files; the originating vendor no longer offers an unrestricted direct download, so this is a public mirror. |
| `tripos-mol2-file-format.pdf` | [Tripos MOL2 File Format](https://seq2fun.dcmb.med.umich.edu/DockRMSD/mol2.pdf) | Originating Tripos format description for MOL2 records; retained from a public academic mirror because the original Tripos URL is no longer available. |
| `pdb-file-format-v3.3.pdf` | [wwPDB PDB File Format v3.3](https://files.wwpdb.org/pub/pdb/doc/format_descriptions/Format_v33_A4.pdf) | Authoritative fixed-column PDB coordinate-file specification. |
| `inchi-technical-manual.pdf` | [IUPAC-InChI technical manual](https://raw.githubusercontent.com/IUPAC-InChI/InChI/dev/INCHI-1-DOC/InChI_TechMan.pdf) | Authoritative InChI layers, normalization, canonicalization, serialization, and InChIKey behavior. |
| `iupac-stereochemistry.html` and `iupac-stereochemistry-*.html` | [IUPAC Basic Terminology of Stereochemistry](https://iupac.qmul.ac.uk/stereo/) | Complete linked HTML edition of the 1996 recommendations used for stereo terminology and semantics. |
| `iupac-chemical-structure-diagrams-2008.html` | [IUPAC Graphical Representation Standards](https://iupac.qmul.ac.uk/drawing/drawing.html) | Authoritative 2D structure depiction and stereo drawing recommendations. |
| `nist-atomic-weights-isotopic-compositions.txt` | [NIST atomic weights and isotopic compositions](https://pml.nist.gov/cgi-bin/Compositions/stand_alone.pl?ascii=ascii) | Reference atomic masses, natural abundances, and standard atomic weights. The response uses HTML around a preformatted text table. |
| `w3c-svg2.html` | [W3C SVG 2](https://www.w3.org/TR/SVG2/) | Authoritative SVG syntax and rendering model for depiction output. |
